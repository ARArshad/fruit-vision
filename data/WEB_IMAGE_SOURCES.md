# Photographs from the web

Alongside the Fruits-360 studio images, the training set contains 148 real-world photographs downloaded from Wikimedia Commons.
They are what teaches the model to cope with a fruit on a table, in a hand or
in a market crate rather than only on a plain white backdrop.

Every one of them is freely licensed (Creative Commons, public domain or
GFDL). The author and licence of each is listed below, and the file page
linked from each row carries the full licence text.
